# Welcome to the Invisible Work Initiative

This repository is where you make your first contribution. Your task:
add your name to `CONTRIBUTORS.md` through a pull request, and get it
merged. When your pull request is merged, you're set up and ready to
work. It's also the toolchain checkpoint from our
[Resources](https://invisible-work-initiative.github.io/resources/) page.

## The task

1. **Fork** this repository (button at the top right of this page).
2. **Clone** your fork to your computer:
   `git clone https://github.com/YOUR-USERNAME/onboarding.git`
3. **Create a branch:** `git checkout -b add-your-name`
4. **Edit `CONTRIBUTORS.md`:** add a line at the bottom in the same
   format as the existing entries.
5. **Commit:** `git add CONTRIBUTORS.md` then
   `git commit -m "Add YOUR NAME to contributors"`
6. **Push:** `git push origin add-your-name`
7. **Open a pull request** from your branch to this repository's `main`
   branch. GitHub will suggest this when you visit your fork. Answer
   the two short questions in the pull request template.

If any step is unfamiliar, that's exactly what this task is for. Work
through [First Contributions](https://github.com/firstcontributions/first-contributions),
which walks through this same process with screenshots, then come back.
The [Resources](https://invisible-work-initiative.github.io/resources/)
page lists more help, and nobody is tracking how long this takes you.
What matters is the merged pull request at the end.

## Ground rules

- One pull request per person, adding only your own line.
- Questions are welcome and public, like everything else here: open an
  issue in this repository and someone will help.
